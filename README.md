Разработана небольшая переиспользуемая библиотека хранения и обработки однотипных
данных. Библиотека устроена так, что одна и та же реализация работает с разными типами
данных без дублирования кода.
Проект состоит из двух проектов решения:
1. DataFlow.Core — библиотека классов: обобщённые классы, структура, делегат,
интерфейсы, методы расширения. Не содержит предметных типов и ничего не знает о
вашей области данных.
2. DataFlow.Demo — консольное приложение: конкретные типы вашей предметной
области и сценарий, который использует ядро так, чтобы были видны все возможности
библиотеки.
